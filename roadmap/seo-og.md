## Goal
When the link is shared it should unfurl as the artwork, and be indexable.

## Delivered
Open Graph + Twitter Card tags, `theme-color`, canonical; a generated `og.png`
(1200×630, built from a real hero screenshot so the wordmark matches the site, with
the signing-point line). `robots.txt` + `sitemap.xml`. Share title uses the house
middot separator.
