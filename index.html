In 1959 Jean Tinguely built a machine that drew abstract art on a conveyor belt — a joke about the spontaneous genius. This machine draws too. But it does not randomize its works; it retrieves them from a space where every possible drawing is already a point. The belt never stops, never repeats exactly — and yet never creates anything new. The counter counts. The originals remain zero.
